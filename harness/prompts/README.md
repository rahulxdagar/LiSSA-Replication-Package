# Prompt texts for RQ2 and RQ3 (DRAFTS: review before any reported run)

The harness reads these files exactly as they are, so they can be edited without changing code. A run records the hashes of these files in its `run.json`.

**Freeze them before the dev-slice runs.** Changing a text afterwards changes every prompt, so the cached answers no longer apply and the run has to be repeated.

| File | Used by | Status |
|---|---|---|
| `definition.txt` | RQ2 variant `definition` | Draft; Prabhjot to rewrite or approve |
| `project-<project>.txt` | RQ2 variant `project` | Drafts written from the dataset READMEs and use-case names; about the same length each |
| `examples-<project>.txt` | RQ2 variant `examples` | Generated by `prepare_prompts.py`. Two real labelled pairs from the other projects' dev slices: one linked, one retrieved but not linked |
| `claims.txt` | RQ3 step 1 (claims) | Draft. Placeholders: `{requirement}`, `{code}` |
| `check.txt` | RQ3 step 3 (factored check) | Draft. Placeholders: `{identifier}`, `{element}`, `{claim}` |

**The code summaries** (RQ2 variant `summary`) are not written here. `prepare_prompts.py` generates them from the code into `data/summaries-<project>.json`.
